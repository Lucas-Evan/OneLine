# OneLine Mac 人工验收清单

在真实 macOS 图形桌面、真实中文输入法下逐项确认；自动发送 `QInputMethodEvent` 不能代替候选窗验收。

- [ ] 中文输入法预编辑、候选窗口位置与选词正常，输入不中断、不吞字。
- [ ] 长中文句产生多次视觉折行；Overlay 只显示光标所在视觉行。
- [ ] 长句粘贴后第一次按左右键不突兀跳动；继续跨视觉行、Home/End、多个真实逻辑行的 Up/Down 均正确，光标始终可见。
- [ ] 连续大量删除、删空后立即重新输入英文和中文均正常；撤销/重做正常。
- [ ] 打开 UTF-8/BOM 文件并保存；外部程序改写文件后，原路径保存被阻止且可以另存为。
- [ ] 重启恢复长行中部和末尾光标位置；保存失败时 `!` 可见，恢复成功后消失。
- [ ] 浅色/深色模式、透明度、字体与窗口宽度改变后 Overlay 颜色和位置正确。
- [ ] 始终置顶切换、拖动与缩放、隐藏后经菜单栏图标恢复及退出正常。
