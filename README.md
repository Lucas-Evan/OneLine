# OneLine（一行笔记）

OneLine 是一个只占一行屏幕空间、内部保留完整多行纯文本的悬浮编辑器。当前为阶段三 Mac 开发版；银河麒麟便携版尚未构建或验证。

## 在 Mac 上启动

首次运行，在项目目录执行：

```bash
./scripts/bootstrap-macos.sh
./scripts/run-macos.sh
```

以后只需执行 `./scripts/run-macos.sh`。依赖安装在项目内的 `.venv`。右侧 `⋯` 菜单可以退出；窗口隐藏后可从系统菜单栏的 OneLine 图标恢复或退出。

## 使用方式

- 窗口默认大小为 800 × 56 像素。左侧 `⋮⋮` 是拖动手柄，鼠标悬停提示“拖动窗口”；最右侧窄区域调整宽度。
- Enter 创建真实换行；↑/↓ 在真实逻辑行之间切换，Home/End 到真实行首/行尾。长行由 `QPlainTextEdit` 按窗口宽度视觉折行；编辑区上方的透明鼠标事件遮挡层仅遮住当前光标视觉行以外的文字，不改变文档、光标或 Qt 原生滚动。外层窗口固定 56 像素。
- 视觉折行不会写入文件，也不会进入复制内容；文件中的真实换行和 `QTextDocument` 段落结构保持不变。
- 输入、退格和 Delete 沿用 Qt 原生处理；没有自定义删除事务。
- 右侧依次显示当前行/总行数、保存状态（`✓` 已保存、`●` 未保存、`⟳` 正在恢复、`!` 自动恢复暂不可用）及菜单按钮。会话写入失败不打断编辑，下一次写入成功后状态恢复。
- 菜单直接提供新建、打开、保存、另存为、查找、最近五个文件、置顶、设置和退出。
- 设置可调整编辑字体、字号、窗口不透明度、深色模式、启动恢复、启动置顶和隐藏快捷键。
- 查找会打开独立小窗口，不改变主窗口高度；“上一个”“下一个”可跨整个文档循环查找。

| 操作 | macOS | Linux |
| --- | --- | --- |
| 新建 / 打开 / 保存 / 另存为 | ⌘N / ⌘O / ⌘S / ⇧⌘S | Ctrl+N / Ctrl+O / Ctrl+S / Ctrl+Shift+S |
| 查找 | ⌘F | Ctrl+F |
| 撤销 / 重做 | ⌘Z / ⌘⇧Z | Ctrl+Z / Ctrl+Y |
| 始终置顶 | ⇧⌘T | Ctrl+Shift+T |
| 退出 | ⌘Q | Ctrl+Q |
| 隐藏当前窗口 | Esc | Esc |
| 隐藏（可在设置中修改） | ⇧⌘Space | Ctrl+Shift+Space |

菜单右侧由 Qt 自动显示当前平台的快捷键。Esc 在菜单打开时先关闭菜单；在编辑区使用时隐藏窗口。隐藏后可从 OneLine 系统菜单栏图标恢复。当前可修改的隐藏快捷键属于 OneLine 窗口快捷键；隐藏或切换到其他软件后，恢复入口是托盘/菜单栏图标。Qt 5.15 的窗口快捷键不会在其他软件获得焦点时触发。

如果系统没有托盘，隐藏操作会最小化 OneLine，保留任务栏或 Dock 入口。

## 文件、最近文件与恢复

读取和保存 UTF-8 TXT，支持 UTF-8 BOM。保存沿用文件的主要换行格式，并通过 Qt `QSaveFile` 原子写入；失败时显示错误并保留未保存状态。如果打开的文件已被其他程序改写，保存会停止并提示另存为，避免静默覆盖磁盘版本。修改后关闭、新建或打开其他文件时，会显示“保存 / 不保存 / 取消”。

最近文件列表只在 Qt 用户级设置中保存最多五个绝对路径。独立的 `session.json` 记录文本、光标、当前行、当前文件路径、窗口位置、宽度和置顶状态。意外退出后，未保存内容恢复到编辑器并保持未保存状态；恢复稿会解除原文件路径关联，需要另存为，不能直接写回 TXT。可以在设置中关闭启动恢复，关闭时会清除本地会话快照。窗口设置还包括主题、编辑字体、字号、不透明度与快捷键。

会话快照在文本改变后延迟写入；仅移动光标不会重写完整长文本。隐藏或正常关闭时仍会记录最新光标位置。

## 测试

```bash
./scripts/test.sh
```

`./scripts/test.sh` 默认仅运行标记为 `release` 的当前架构测试（Qt offscreen）。它覆盖固定高度、视觉行遮挡、主题切换、长文本输入和删除、中文输入法事件模拟、逻辑行导航、折行后的保存与复制、文件保存往返、关闭提示、重启恢复、窗口状态、查找、菜单、最近文件、设置及快捷键。离屏插件与图形后端的程序性光标滚动几何不同，因此长行恢复后的可见性用例在 offscreen 跳过，须在 macOS Cocoa 图形后端单独通过。

旧架构与诊断测试未删除，使用 `./scripts/test-all-diagnostics.sh` 单独运行，允许反映已废弃私有 API 或历史性能问题；视觉折行性能 A/B 使用 `./scripts/benchmark.sh`，会话保存耗时使用 `./scripts/benchmark.sh session`，均不进入默认发布门禁。测试分类见 `tests/conftest.py`。

仍需在 Mac 图形界面人工确认：中文输入法预编辑和候选框、真实拖动与缩放、系统菜单栏图标、隐藏后恢复、不同屏幕缩放比例、字体和透明度。Linux 兼容性准备说明见 [docs/platform-notes.md](docs/platform-notes.md)。

正式分发前须确认 PyQt5 的发行许可安排：GPL 兼容的发布方式，或适用的商业许可。本项目目前不迁移 PySide，也不在此作法律结论。发行范围应排除 `.venv`、`__pycache__`、`.pytest_cache`、benchmark、旧 rollback/diagnostic 测试及实验文件。
